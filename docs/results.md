# Web2KG 在 Reddit-Verified 上的结果

Web2KG 使用 225 节点图谱和 Qwen3.7-flash，在启用根因定位的两批实验中共完成 106 道单站点 Reddit 任务，75 道获得官方成功评分。

| 任务 | 成功 | 题数 | 成功率 |
|---|---:|---:|---:|
| Hard | 32 | 42 | 76.19% |
| 非 Hard | 43 | 64 | 67.19% |
| 合计 | 75 | 106 | 70.75% |

[下载逐题评分及来源（JSON）](results/reddit-verified-225.json)。每题提供编号、难度、官方得分、源批次和原始评分文件的 SHA-256。

Hard 沿用既有归档选定的尝试。早期 41 题汇总排除了 724，本表按完整题集纳入该题原始审核失败的 0 分。非 Hard 取全量比较第六阶段汇总所引用的 225 节点组 64 题。每个任务只计一次。

两个批次在代码、提示词、行动预算计数和知识积累过程上有差异。这些任务已在开发中使用。合计成功率描述这批历史运行的成绩，无法单独估计根因定位带来的收益。
